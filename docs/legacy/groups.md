# Группы

Источник: `lib/features/groups/groups_screen.dart`. Редактор событий общий с личными, см. [events.md](events.md).

## Список

`GET /api/v1/groups/list` при открытии и pull-to-refresh.

- ошибка — «Группы не загрузились» и retry;
- загрузка — индикатор;
- пусто — «Собери свою первую группу» / «Добавляй друзей и создавай общие встречи.», кнопка панели вызывает создание;
- иначе сетка 2 колонки. Плитка: первая буква имени, имя, «N участников» (длина `members` в объекте списка; если список их не прислал, будет 0).

«+» в app bar — диалог «Новая группа», поле «Название». Пустая строка или отмена ничего не шлют. Иначе `POST /api/v1/groups/create` `{name}`, список обновляется, открывается карточка с возвращённым id, после возврата список грузится снова. Ошибка создания — snackbar.

Тап плитки открывает карточку и по возврату обновляет список.

## Карточка группы

Параллельно `getGroup(id)` и `listEvents(groupId)`.

- ошибка — «Не удалось открыть группу» и retry;
- загрузка — индикатор, кнопки добавления участника выключены, пока группы нет;
- успех — refresh на весь список.

Шапка: имя группы. Горизонтально участники (`FriendInfo`) и кружок «Добавить».

Кнопки:

- «Найти общее время» — дата от вчера до +365 дней, `POST /api/v1/groups/:id/free-time` с `{date: YYYY-MM-DD}`. Sheet «Общие окна». Пусто: «В этот день общего свободного времени нет». Ошибка — snackbar.
- «Подтвердить время» — дата от сегодня до +365 дней, затем time picker. Локальные дата и время уходят как `confirmedTime` в UTC ISO на `POST /api/v1/groups/:id/confirm`. Успех: «Время подтверждено». Список событий после этого не перезагружается. Отмена любого пикера прерывает сценарий.

События группы: счётчик, пусто «Пока нет общих событий», иначе карточки с датой `d MMMM · HH:mm` начала. Тап — тот же sheet деталей, `groupId` передаётся в edit/delete. Успех перезагружает карточку.

FAB создаёт событие через `EventEditorScreen(groupId: ...)`. Успех (`pop(true)`) перезагружает карточку.

## Участник

Диалог «Добавить друга», поле «Ник друга», без проверки что это друг. Пустое значение не отправляется. `POST /api/v1/groups/:id/members` `{username}`, затем полная перезагрузка карточки. Ошибка — snackbar.

Удалить участника отдельной кнопкой нельзя.

## Выход и удаление

Меню: «Выйти из группы» и «Удалить группу». Клиент не проверяет, владелец ли текущий пользователь (`ownerId` в модели есть, в меню не используется). Оба пункта доступны всегда.

Подтверждение:

- удаление — «Группа и её события будут удалены для всех участников.» → `DELETE /api/v1/groups/:id`;
- выход — «Вернуться можно будет только по новому приглашению.» → `POST /api/v1/groups/:id/leave`.

Успех закрывает карточку с `true`. Ошибка остаётся на карточке.
