# Главная и события

Источники: `lib/features/home/home_screen.dart`, `lib/features/events/event_editor_screen.dart`.

Личные и групповые события используют один редактор и один bottom sheet деталей. Отличие — `groupId`: без него пути `/api/v1/events/...`, с ним `/api/v1/groups/:id/events/...`. Тип по умолчанию для нового личного события — `personal`, для группового — `meeting`.

## Загрузка главной

В `initState` параллельно:

- `listEvents()` — личные;
- `listFriends()`;
- `listGroups()`;
- `incomingRequests()` — только длина, для бейджа.

События сортируются по `startTime` по возрастанию. Активный индекс героя зажимается в диапазон списка. Пока идёт повторная загрузка при уже показанных данных, `_refreshing` показывает маленький индикатор у заголовка «Твои события». Pull-to-refresh на нижней панели вызывает тот же `_load`.

Состояния героя:

- нет данных и нет ошибки — белый индикатор по центру;
- ошибка и данных ещё не было — панель «Не удалось загрузить расписание» и retry;
- пустой список — пустой герой с созданием встречи;
- иначе герой активного события, тап открывает детали.

`ApiException.isUnauthorized` на этой загрузке вызывает `session.logout()` и уводит на welcome. Другие ошибки остаются текстом на экране. Если данные уже были, ошибка повторной загрузки не затирает список: код выставляет `_error`, но ветка панели показывается только при `_events == null`.

После создания события — перезагрузка и snackbar «Встреча создана». После уведомлений, друзей, списка групп и карточки группы главная перезагружается при возврате. Плитка «Добавить» у групп открывает список и главную сама не обновляет.

## Композиция главной

Верхняя панель поверх градиента события (палитра от `type` и id):

- буква дня недели (`E`, ru, без точки, верхний регистр) открывает личное свободное время;
- до пяти точек переключают героя, если событий больше одного; в горизонтальном списке событий больше пяти, точки показывают только первые пять;
- «+» создаёт личное событие;
- колокольчик, бейдж — число входящих заявок, если оно > 0;
- настройки.

Нижняя шторка (`DraggableScrollableSheet`, высоты 0.19 / 0.29 / 0.78): горизонтальные карточки событий плюс плитка создания, аватарки друзей или кнопка «Найти друзей», плитки групп и «Добавить». Тап карточки события только меняет героя, не открывает редактор. Тап героя открывает детали.

## Редактор

Заголовок «Новая встреча» или «Редактировать».

Начальные значения нового события: завтра 19:00, окончание через 2 часа, тип как выше. Существующее событие подставляет свои поля.

Валидация:

- название после trim не пустое — «Добавь название»;
- окончание строго позже начала — «Окончание должно быть позже начала».

Дата: от вчера до +730 дней. Смена даты сохраняет время и длительность. Смена начала сохраняет длительность (если длительность отрицательная — ставит 1 час). Смена окончания, если время не позже начала, переносит конец на следующий день.

Типы-чипы: `personal` «Личное», `work` «Работа», `meeting` «Встреча», `sport` «Спорт». На сервер уходит строковый `type` как есть.

Создание вызывает `createEvent` и игнорирует возвращённый id на экране: route закрывается с `true`. Редактирование — `updateEvent`. Ошибка остаётся на форме.

## Детали и удаление

`openEventDetails` — modal bottom sheet: название, дата `EEEE, d MMMM` и интервал `HH:mm—HH:mm`.

- «Редактировать» открывает редактор с тем же `groupId`. Успех закрывает sheet с `true`, родитель перезагружает список.
- «Удалить» спрашивает «Удалить встречу?» / «Это действие нельзя отменить.» Подтверждение вызывает `deleteEvent(id, groupId)` и закрывает sheet с `true`. Отмена ничего не шлёт.

## Свободное время

Личное: выбор даты от вчера до +365 дней, `freeTime(date)` без `groupId`, sheet «Твоё свободное время». Пустой список: «Свободных окон в этот день нет». Иначе строки `HH:mm—HH:mm`. Ошибка — snackbar, sheet не открывается.

Дата в теле запроса — `YYYY-MM-DD` локального календарного дня, не полный timestamp. Слоты приходят в local.
