# Аватар: цвета и шрифты

Для разработчика, который будет менять палитру или шрифты буквы. Дизайн-решения
описаны в `docs/design-system.md` (§2.3, §9.9, §9.11), здесь — как это устроено
в коде и что делать, чтобы ничего не сломать.

## Как устроен аватар

У людей нет фото. Аватар (`PersonAvatar`, `lib/shared/ui/person_avatar.dart`) —
это:

1. **Круг с градиентом 45°**: основной цвет сверху слева, его тень снизу справа
   (`avatarGradient`).
2. **Первая буква имени** выбранным шрифтом, в регистре этого шрифта, выровненная
   по центру на глаз (`AvatarLetter`).

Свой цвет и шрифт пользователь выбирает на шаге «Профиль» онбординга и в профиле
в настройках. Сервер их пока не хранит, они лежат на устройстве (`AppSettings`):
`ownColorSlot` — индекс цвета, `ownFontId` — id шрифта. Друзья получают цвет по id
и шрифт по умолчанию, пока сервер не начнёт отдавать их выбор (контракт —
`docs/backend-changes.md`, «Цвет и шрифт аватара»).

Мой аватар везде, где он показан, берёт мой цвет и шрифт из `OwnAvatar`
(`InheritedWidget` над `HomePager`). Передавать их вручную в каждый
`PersonAvatar` не нужно.

| Что | Где |
|---|---|
| Палитра, цвет по id, `PersonAvatar`, `OwnAvatar` | `lib/shared/ui/person_avatar.dart` |
| Градиент, тень, шрифты, центровка буквы | `lib/shared/ui/avatar_style.dart` |
| Превью аватара, выбор шрифта и цвета | `lib/shared/ui/profile_pickers.dart` |
| OKLab | `lib/shared/ui/oklab.dart` |
| Хранение выбора | `lib/app/app_settings.dart` (`ownColorSlot`, `ownFontId`, `ownColorFor`, `ownFontFor`) |
| Экран подгонки | `lib/features/settings/avatar_tuning_page.dart` |
| Шрифты | `assets/fonts/`, `assets/fonts/avatar/`, `pubspec.yaml` |

## Цвета

### Палитра

`avatarPalette` в `person_avatar.dart` — 8 цветов, в порядке пикера (4 × 2):

| # | Цвет | | # | Цвет |
|---|---|---|---|---|
| 0 | `#34C759` зелёный | | 4 | `#FF2D78` розовый |
| 1 | `#FFD60A` жёлтый | | 5 | `#AF52DE` фиолетовый |
| 2 | `#FF9500` оранжевый | | 6 | `#0A84FF` синий |
| 3 | `#FF3B30` красный | | 7 | `#30C8D6` голубой |

Палитра одна на всё приложение: мой цвет, цвета друзей, мои события в календаре,
моя часть градиента приглашений, фон онбординга после шага «Профиль».

### Как менять

- **Поменять оттенок** — замените значение на месте. Пользователи, выбравшие этот
  слот, увидят новый оттенок.
- **Добавить цвет** — только в конец списка. Выбор хранится индексом: вставка в
  середину сдвинет цвета у всех. Пикер раскладывает цвета по 4 в ряд, новая строка
  появится сама.
- **Убрать цвет** — лучше заменить его другим на том же месте. Если список всё же
  стал короче, сохранённый индекс за его концом сбросится (`AppSettings.load`), и
  пользователь получит цвет по id.
- **Цвет друга** по id: `avatarSlotFor(id) = (id × avatarHueStride) mod N`. Шаг
  должен быть взаимно прост с длиной палитры (сейчас 3 для 8), иначе часть цветов
  никому не достанется. Поменяли длину — проверьте шаг и тест
  `test/person_avatar_test.dart`.
- **Буква** белая на всех цветах, и на жёлтом тоже (`avatarInk`, ✅
  2026-11-02).

### Тень градиента

`avatarShade(base)` переводит цвет в OKLab и умножает яркость на
`avatarShadeFactor` (0.72). Если более тёмный цвет выходит за sRGB, насыщенность
уменьшается ровно настолько, чтобы остаться внутри. Тон при этом не меняется:
простое обрезание превращало оранжевый в красный, а жёлтый в оливковый.

Хотите тень глубже или мягче — меняйте только `avatarShadeFactor`.

## Шрифты буквы

### Описание шрифта

Каждый шрифт — запись `AvatarFont` в списке `avatarFonts`
(`avatar_style.dart`). Порядок в списке — порядок в пикере.

| Поле | Что значит |
|---|---|
| `id` | Ключ, под которым хранится выбор. **Не меняйте у шрифта, который уже выбирали.** |
| `label` | Название для VoiceOver. |
| `family` | Имя семейства из `pubspec.yaml`. |
| `weight` | Начертание; у вариативного шрифта задаётся через ось `wght`. |
| `uppercase` | Регистр буквы: `true` — заглавная, `false` — строчная. |
| `scale` | Кегль как доля диаметра круга. |
| `dx`, `dy` | Сдвиг на глаз как доля диаметра: `+dx` вправо, `+dy` вниз. |
| `capHeight` | Высота заглавной, доля em (`sCapHeight` из таблицы OS/2). |
| `xHeight` | Высота строчной без выносных, доля em (`sxHeight`). |
| `ascender` | Высота строчной с верхним выносным (б, d, k); по умолчанию `capHeight × 1.04`. |
| `descender` | Глубина нижнего выносного (у, р, д, g, Щ); по умолчанию 0.22. |

### Как центруется буква

Буква центруется по своей «чернильной» части, а не по строке текста. Иначе
заглавные висели бы низко, а строчные проваливались бы вниз.

1. По букве и шрифту выбирается рамка чернил (`inkBox`):
   - сверху — высота заглавной, строчной или выносного;
   - снизу — базовая линия или глубина нижнего выносного.
2. Базовая линия ставится так, чтобы середина этой рамки совпала с центром круга.
3. По горизонтали буква центруется по ширине.
4. Сверху добавляются `dx` и `dy` из описания шрифта.

Списки букв с выносными — `_ascenders` и `_descenders` в `avatar_style.dart`.
Встретилась буква, которая стоит криво во всех шрифтах, — сначала проверьте её
там.

### Как добавить или заменить шрифт

1. **Файл.** Шрифт должен быть под свободной лицензией (OFL) и **с кириллицей** —
   имена в основном русские. Положите TTF в `assets/fonts/avatar/`, лицензию
   рядом (`<Имя>-OFL.txt`).
2. **`pubspec.yaml`.** Добавьте семейство в `flutter: fonts:`, как у
   `PlayfairDisplay` и остальных.
3. **Метрики.** Возьмите `sCapHeight`, `sxHeight` и `unitsPerEm` из таблицы OS/2
   и разделите на `unitsPerEm`. Подойдёт любой просмотрщик шрифтов или
   `fontTools`: `ttx -t OS/2 font.ttf`.
4. **Запись.** Добавьте `AvatarFont` в конец `avatarFonts`. Заменяете шрифт
   целиком — заведите новый `id`: старый выбор пользователей упадёт на шрифт по
   умолчанию (`avatarFontById`), а не на случайный.
5. **Подгонка** на экране «Подгонка аватаров» (ниже). Вставьте результат в код.
6. **Проверка.**
   - `flutter test` — `test/avatar_style_test.dart` следит, что шрифтов 6 и id не
     повторяются. Поменяли число — поправьте тест.
   - `flutter build ios --simulator --debug`.
   - Посмотрите шаг «Профиль» и профиль в настройках на устройстве.

### Экран подгонки

Настройки → «Демо-данные» → **«Подгонка аватаров»**. Только вне production.

- **Сверху** — кнопки шрифтов.
- **Большой круг** — выбранная буква в регистре шрифта.
- **Сетка** — набор букв в обоих регистрах: А, Б, Д, Ж, Щ, N, а, б, д, у, g. Тап
  по букве выводит её в большой круг.
- **Направляющие**: перекрестие через центр и рамка чернил. Буква стоит ровно,
  когда рамка делится перекрестием пополам и **на глаз** тоже выглядит по
  центру. У рукописных и асимметричных букв глазу верят больше, чем рамке.
- **Ползунки** `scale`, `dx`, `dy` меняют выбранный шрифт сразу во всех кругах.
- **Ниже** — готовый код `AvatarFont(...)`. «Скопировать значения» кладёт его в
  буфер; замените им запись в `avatarFonts`.

Экран ничего не сохраняет: значения живут, пока он открыт.

### Чек-лист перед заменой шрифта

- [ ] OFL, лицензия рядом, есть кириллица.
- [ ] Семейство в `pubspec.yaml`, `id` новый или прежний — осознанно.
- [ ] `capHeight` и `xHeight` из OS/2.
- [ ] На экране подгонки ровно стоят А, Ж, Щ, а, б, у и латиница.
- [ ] Буква читается в пикере (52 pt) и в маленьких аватарах (24–26 pt) в
      списках и на событиях.
- [ ] Тесты и сборка iOS проходят.
